# Сервис учёта посылок
## Назначение
Данное приложение представляет собой систему учёта посылок, помогает структурировать данные и получать данные посылок по фильтрам
## Целевая аудитория
Целевой аудиторией являются:  
- Сотрудники склада и аналитики почтовых сервисов
- Пользователи, что заказывают или отправляют посылки
## Предметная область
Сервис предоставляет возможность вести учет совершенных отправлений посылок, создавать списки посылок, отслеживать статус посылок.  
Пользователи могут планировать заказ и получение посылок, а сотрудники анализировать заказы пользователей.  
Приложение позволяет хранить историю посылок, группировать посылки по категориям и формировать статистику.
## Основные сущности
- Пользователь - аккаунт пользователя сервиса, который может быть получателем или отправителем
- Сотрудник - аккаунт пользователя сервиса, который может получать доступ ко всему списку отправлений
- Посылка - конкретная посылка с полной информацией о ней
## Основные функции
- Создать посылку
- Получить список всех посылок
- Проверить статус посылку
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
